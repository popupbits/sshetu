SSHetu is an SSH client for iPhone and iPad. It keeps the servers you look after in one place and gives you a real terminal, a file browser over SFTP, port forwarding, and SSH keys you can generate on the device.

There is no SSHetu account and no SSHetu server. Your hosts, keys, tunnels and known-host fingerprints stay in a database on this device, your credentials stay in the Keychain, and nothing is sent anywhere except to the server you are connecting to.

A TERMINAL THAT HOLDS UP ON A PHONE

A VT/xterm emulator with an adjustable grid, search, adjustable text size, and a key bar carrying the Ctrl, Alt, Esc and arrow keys the software keyboard leaves out. When the server has tmux, each tab runs inside it, so a connection dropped in a tunnel or a lift picks up where it left off instead of losing what was running. If tmux is missing, SSHetu offers to install it and shows you the exact command before it runs.

FILES AND TUNNELS

Browse the remote filesystem over SFTP: upload, download, rename, change permissions, and open a remote file in a text editor that notices when the file changed under you rather than overwriting it. Local and remote port forwards are saved and started from a list, with the far end watched while they run.

KEYS

Generate an Ed25519 key on the device, or ECDSA and RSA if a server requires one, or import the keys you already have in OpenSSH, PEM or PuTTY format. Still signing in with a password? SSHetu installs a key for you, proves it works over a second, independent connection, and only then deletes the password. It never edits sshd_config, because turning off password authentication affects everyone who uses that server.

BRING YOUR SETUP WITH YOU

SSHetu reads an existing ~/.ssh/config, its keys and its known_hosts, so you are not retyping servers you already wrote down. It reads those files and never writes to them. Moving to a second device is a direct transfer over your own network, sealed with a single-use secret carried in a QR code, and the backup is an encrypted file you keep yourself.

ALSO IN THE APP

Snippets for commands you run often, with placeholders that ask for a value when you use them. A command palette across servers, tabs, snippets and actions. A panel of server statistics. Session logging, off by default, written to a folder you choose. An optional lock that asks for Face ID, Touch ID or your passcode before a saved password or key is used. Jump hosts, groups and tags, and known-host pinning with a fingerprint you can check by eye.

SSHetu is in English and Nepali.

WHAT IT DOES NOT DO

There is no cloud sync, and that is on purpose: an app holding the keys to your infrastructure has no business keeping a copy of them on someone else's machine. Nepali printed by a remote shell is readable in the terminal but does not line up, because no monospaced Devanagari face exists.
